# Non-Dev Harness

비개발자 프로젝트 하네스. 3개 명령만 사용.

## 명령어
- /hs — 하네스 세팅 (최초 1회)
- /ci — 체크인 (세션 시작)
- /co — 체크아웃 (세션 종료)

## 파일 역할
| 파일 | 용도 | 정보 계층 |
|------|------|----------|
| CLAUDE.md | 프로젝트 규칙 (자동 로드) | Rules |
| MEMORY.md | 세션 이력, 의사결정, TODO | History |
| ERROR.md | 에러+해결 이력 | Errors |
| ISSUE.md | 미해결 이슈/할 일 | Tasks |
| WIKI.md | 프로젝트 영구 지식 | Specs |

## 원칙
- 비유 우선, 전문용어 최소화
- 파일 수정 전 사용자 확인 필수
- 불확실하면 묻기 (가정으로 진행 금지)
- 응답 간결하게, 핵심만
- 큰 파일은 offset/limit으로 필요한 부분만 읽기
- 같은 파일 중복 읽기 금지

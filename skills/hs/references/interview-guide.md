# 인터뷰 가이드 (상세)

## 가설-확인 인터뷰 방식

interview-me 패턴: 가설을 먼저 제시하고 사용자가 확인/수정하는 방식.

### 진행 순서

1. 폴더명에서 프로젝트 이름 추론 → "프로젝트 이름이 '[폴더명]'이 맞나요?"
2. 폴더 내 파일을 읽어 프로젝트 유형 추론 → "이 프로젝트는 [추론]인 것 같은데 맞나요?"
3. 대상은 자유 입력 → "누구를 위한 프로젝트인가요?"
4. 기술 스택 자동 감지 → package.json, requirements.txt 등으로 추론. 없으면 "기술 스택이 있나요? 없으면 '없음'이라고 해주세요"
5. 언어는 기본 한국어 → 영어로 대화 중이면 영어로 전환

### 95% 규칙

인터뷰 종료 조건: "사용자의 다음 3개 질문을 예측할 수 있으면 인터뷰 종료"

충분한 정보가 모이면 일찍 종료해도 됨. 5문 모두 묻지 않아도 된다.

### 비개발자 배려

- "기술 스택"이라는 용어 대신 "어떤 도구나 프로그램을 쓰시나요?"
- "없음/모름"은 항상 유효한 답변
- 추가 질문은 사용자가 원할 때만

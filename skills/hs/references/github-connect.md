# GitHub 연결 (선택)

공개 저장소로 만들면 작업 폴더가 인터넷에 공개되므로 비공개(`--private`)로만 만듭니다. 공개(`--public`)는 사용자가 따로 공개를 요청할 때만 씁니다.

## 제안 조건 (모두 맞을 때만)
- 6-7 커밋이 성공했습니다. Cowork 확인 창을 거절해 커밋을 건너뛰었으면 제안하지 않습니다.
- 하네스 루트에서 `git rev-parse --show-prefix`의 출력이 빈 줄입니다(하네스 루트가 저장소 최상위). 비어 있지 않으면 "이 폴더는 더 큰 저장소의 일부라서 GitHub에 올리면 그 저장소 전체가 올라갑니다"라고 설명하고 건너뜁니다.
- `gh auth status`가 성공합니다(gh가 설치되어 있고 로그인됨).
- `git remote get-url origin`이 **실패**합니다. 즉 원격 저장소가 아직 **없을 때만** 제안합니다. 이미 원격이 있으면 제안하지 않습니다.

## 묻고 실행하기
- 질문은 선택지 질문 도구로 합니다. 글 질문으로 묻지 않습니다(입력창의 회색 제안 문구에서 Enter 한 번으로 저장소가 만들어질 수 있습니다).
- 저장소 이름은 영문 소문자와 하이픈으로 정해(한글 이름은 그대로 쓰지 않음) 질문 문장에 넣고("GitHub에 'my-blog' 비공개 저장소로 백업할까요?"), 비공개로 연결 / 나중에 가운데 고르게 합니다. 이름을 바꾸고 싶으면 기타(Other)로 받습니다.
- "비공개로 연결"을 골랐을 때만 실행합니다.

```
gh repo create <이름> --private --source="<하네스 루트>" --remote=origin --push
```

## 건너뛰는 경우
`gh`가 없거나 로그인되어 있지 않거나, Cowork처럼 push가 막히는 환경이면(명령이 `Cowork blocked this request`로 막힌 경우 포함) 실패로 다루지 않고 "GitHub 백업은 나중에 내 컴퓨터의 터미널이나 Claude Code에서 언제든 할 수 있어요"라고 안내하고 건너뜁니다.

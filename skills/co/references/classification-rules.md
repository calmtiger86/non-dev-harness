# 체크아웃 분류 규칙 (상세)

## 6가지 분류 유형

### 1. 규칙 → CLAUDE.md
- 이 프로젝트에서 항상 적용되는 관례
- 예: "이 프로젝트에서는 항상 한국어로 작성", "파일명은 kebab-case"
- 반드시 1줄로 압축
- 일반 상식이나 일시적인 것은 제외

### 2. 의사결정 → MEMORY.md
- A 대신 B를 선택한 이유
- 고려한 대안과 기각 사유
- 예: "블로그 플랫폼으로 X 선택. Y는 비용 때문에 기각"

### 3. 세션 요약 + TODO → MEMORY.md
- 오늘 한 일 (1-2문장)
- 다음에 할 일 (구체적)
- "마지막 세션" 섹션은 항상 덮어쓰기 (이전 내용 대체)

### 4. 에러 → ERROR.md
- 유형 태그 필수: `[환경]` `[코드]` `[연동]` `[데이터]` `[권한]`
- 시도한 복구 방법 기록
- 해결됨 → 미해결에서 해결됨으로 이동
- 패턴 발견 시 → WIKI.md "교훈"으로 승급 제안

### 5. 이슈 → ISSUE.md
- 우선순위 부여: 🔴 높음 · 🟡 중간 · 🟢 낮음
- 해결됨 → 미해결에서 해결됨으로 이동

### 6. 영구 지식 → WIKI.md
- 프로젝트 고유 학습
- 외부에서 찾기 어려운 정보
- 적절한 카테고리 선택: 일반/기술/워크플로우/교훈

## 포함/제외 기준 (Anthropic 공식 가이드라인)

### 포함
- 프로젝트 고유한 것 (다른 프로젝트에서는 다를 수 있는 것)
- 재현 불가능한 학습 (시행착오로 알게 된 것)
- 환경 특이사항 (특정 설정이 필요한 이유)
- 향후 세션에 도움이 되는 것

### 제외
- 일반 상식 (검색하면 나오는 것)
- 1회성 에러 (재발 가능성 없음)
- 코드에서 바로 읽히는 것 (변수명이 설명하는 것)
- 이번 세션에서만 의미 있는 임시 정보

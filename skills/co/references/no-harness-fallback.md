# 하네스가 없을 때의 체크아웃 (대체 분기)

- 기록 파일 5개(CLAUDE.md, JOURNAL.md, ERROR.md, ISSUE.md, WIKI.md)를 만들지 않습니다. /hs를 강요하지 않습니다.
- 이번 세션의 결정, 배운 점, 에러, 남은 일을 정리합니다.
- 프로젝트에 이미 있는 기록처(README, 기존 노트나 변경 기록 파일)를 고릅니다. 알맞은 곳이 없으면 현재 폴더에 `NOTES.md` 하나만 만듭니다.
- 무엇을 어디에 적을지 일반 글로 먼저 보여 주고, 선택지 질문 도구로 확인받은 뒤에만 저장합니다. 기존 파일은 Edit로 해당 부분만 고칩니다.
- 그다음 SKILL.md의 1~5단계를 건너뛰고, 현재 폴더를 `<루트>`로 삼아 6단계 git 저장으로 갑니다.
- 현재 폴더가 SKILL.md의 위험 폴더 목록 (가)나 (나)에 들면 git 저장은 건너뛰고 '7. 체크아웃 요약'으로 갑니다.
